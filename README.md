# 🤖 Multimodal AI Chatbot

A free, feature-rich Streamlit chatbot that supports text, image analysis, audio recording/transcription, and video understanding using the Gemini 2.5 Flash API.

## Features
- 💬 **Text Chat**: Fast, context-aware conversational AI.
- 🖼️ **Image Understanding**: Upload images and ask questions or request descriptions.
- 🎙️ **Voice & Audio Support**: Record directly from your microphone or upload audio files.
- 🎥 **Video Analysis**: Upload videos for scene understanding and summarization.
- 🎨 **Warm Sunset Theme**: Soft linen background with warm coral and sand glassmorphism cards.

## Prerequisites
Get a free Gemini API key from [Google AI Studio](https://aistudio.google.com/).

## Local Setup
```bash
pip install -r requirements.txt
streamlit run app.py
